# Atom Thumbnail Portfolio

This repository contains the public static portfolio for GitHub Pages.

The local admin panel and Node backend are intentionally not included. They remain private on the owner’s PC at `http://127.0.0.1:4174` and `http://127.0.0.1:4173`.

GitHub Pages serves a static snapshot. Content changes made in the local admin panel continue to update the local portfolio immediately, but they require a separate publish step before appearing on GitHub Pages.
